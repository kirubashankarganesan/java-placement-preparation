polymorphism --> poly means many and morphism means forms

Polymorphism means one name having many forms. It allows the same method name to perform different behaviors. In Java, polymorphism is mainly achieved through method overloading and method overriding.

Thanglish:
Polymorphism na same method name different situations-la different behavior kudukkuradhu.

In simple words:

One method → Many forms/behaviors

There are two types:

Method Overloading → Compile-time polymorphism
Method Overriding → Runtime polymorphism

1. Method Overloading

Same method name, but different parameters.

Same method name + different parameters = Method Overloading

2. Method Overriding

Parent and child class have the same method, but the child provides its own implementation.

Same method + different implementation = Method Overriding

---

Polymorphism = One name, many forms
Overloading → Same class, same method name, different parameters
Overriding → Parent-child classes, same method, different implementation
