An abstract class is a class declared using the abstract keyword. It cannot be instantiated directly and can contain both abstract methods and normal methods.

An abstract method is a method declared using the abstract keyword without a method body. A concrete child class must provide its implementation.


Easy way to remember
Abstract class → cannot create an object directly.
Abstract method → has no body.
Concrete child class → must implement the abstract methods.
Abstract child class → can leave abstract methods unimplemented.
