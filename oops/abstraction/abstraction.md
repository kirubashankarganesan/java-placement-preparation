Abstraction is the process of hiding the internal implementation details and showing only the essential features to the user.

Abstraction na oru object eppadi work aagudhu-nu internal details-a hide panni, user-ku thevaiyana functionality mattum show pannuradhu

2. Abstraction

ATM-la Withdraw ₹5,000 nu select pannuvom.

But internally:

ATM → Bank Server → Check Balance → Verify PIN → Process Transaction

Idhellam eppadi work aagudhu nu namakku theriyadhu.

Namma just Withdraw option-a use pannuvom.

👉 Internal working-a hide pannuradhu = Abstraction

Real-world example: Car 🚗

Encapsulation:

Car-la engine details, fuel data, etc. direct-ah access panna mudiyadhu. They are protected inside the car.

👉 Data protection = Encapsulation

Abstraction:

Namma car drive pannumbothu accelerator press pannuvom, but engine inside eppadi work aagudhu-nu namakku theriyanum avasiyam illa.

👉 Implementation hiding = Abstraction

Easy to remember 🧠

Encapsulation → Protect the data 🔒
Abstraction → Hide how it works 🙈
