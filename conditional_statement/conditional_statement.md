A conditional statement is used to make decisions in a program. It checks a condition, and if the condition is true, one block of code executes, otherwise, another block executes.

types

| Type                       | Purpose                                                               | Example                         |
| -------------------------- | --------------------------------------------------------------------- | ------------------------------- |
| **1. `if`**                | Executes code only if the condition is true.                          | `if (age >= 18)`                |
| **2. `if-else`**           | Executes one block if the condition is true, otherwise another block. | `if (marks >= 50) ... else ...` |
| **3. `if-else-if` Ladder** | Checks multiple conditions one by one.                                | Grade calculation               |
| **4. Nested `if`**         | An `if` statement inside another `if` statement.                      | Age check and license check     |
| **5. `switch`**            | Selects one block from multiple options based on a value.             | Days of the week                |
