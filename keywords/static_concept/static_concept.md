static - static is a keyword used to make a variable, method, or block belong to the class rather than to individual objects.

Thanglish Concept
Normally, object create pannumbothu each object-kum separate copy create aagum.
But static use pannina, object-ku separate copy create aagathu.
Class-ku one common copy mattum irukkum.

Static = Class-level member → common for all objects

A static method belongs to the class, so we can call it using the class name without creating an object.

Static variable = one common copy shared by all objects of that class.
