1.  What is Java?

    Java is a high-level, object-oriented, platform-independent programming language used to develop
    web applications, desktop applications, mobile applications, enterprise software, cloud applications,
    and many other types of software.

2.  Why was Java developed?

    java was developed to solve the problem of writing separate programs for different operating systems.
    Earlier,
    A C program compiled on Windows could not run directly on Linux.
    A program had to be rewritten or recompiled for each operating system.

    Java introduced the concept of: Write Once, Run Anywhere (WORA)

3.  Who developed Java?

    Developed by James Gosling
    Company: Sun Microsystems
    First released: 1995
    Sun Microsystems was later acquired by Oracle Corporation, which now maintains Java.

4.  Where is Java used?

    Java is commonly used in:

        Web Applications
        Enterprise Applications
        Banking Software
        E-commerce Applications
        Android Applications
        Desktop Applications
        Cloud Applications
        Distributed Systems
        Backend Development

    Examples:

        Banking systems
        Online shopping platforms
        Hospital management systems
        Student management systems

6. Advantages of Java

    Platform Independent
    Object-Oriented
    Secure
    Robust
    Portable
    Multithreaded

7. Limitations of Java

    Slower than languages like C and C++ for some low-level tasks.
    More memory usage compared to some languages.
    Not suitable for low-level system programming such as operating system kernels.
